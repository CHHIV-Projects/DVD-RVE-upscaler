## 6. Multiple Original Source Locations

The store supports one or more enabled source locations. Source creation accepts only a controlled folder relative to:

```text
/mnt/nas/movies
```

Original source roots must be existing directories. Validation rejects:

- absolute paths;
- `..` and traversal;
- backslash-based ambiguous paths;
- paths outside the trusted Movies hierarchy;
- symlink components and symlink escape;
- invalid roles.

Disabling a source removes it from aggregate discovery without changing media or deleting configuration.

Multiple source behavior, disabling, persistence, overlap, and same-name distinct files were validated through local fixtures. No second NAS source folder was created for testing.

## 7. Finished Destination Configuration

Finished destinations use the same stable location registry and trusted-root containment. A planned destination may be configured beneath `/mnt/nas/movies` without requiring the final directory to exist in 0.1.5.

Configuration:

- does not test write access;
- does not grant NAS write authority;
- does not create a folder;
- does not copy, move, rename, or delete media;
- does not imply publication.

Destination movie subfolders reject absolute paths, traversal, backslashes, and symlink escape. Publication must revalidate the destination in 0.1.6.

No real Finished Movie Destination was added during coder validation because the Product Owner has not yet selected the intended safe destination.

## 8. Multi-Root Discovery and Search

Enabled Original DVD Source Locations are discovered recursively using the accepted 0.1.2 MKV rules. Aggregate results retain:

```text
location_id
location_name
relative_path
movie_folder
filename
size_bytes
preparation_eligibility
```

Resolved physical paths are deduplicated across overlapping roots. Distinct files with identical filenames remain separate.

Case-insensitive substring search covers:

- filename;
- containing movie folder;
- source location display name.

The browser retains one bounded in-memory discovery result and filters it locally while the operator types, avoiding a recursive NAS rescan for every keystroke. `Refresh Sources` explicitly reloads configured roots. No persistent media index was added.

Live read-only browser validation searched `Ratatouille` and returned:

```text

Folder: Ratatouille
Location: DVD Intake
Preparation: Eligible
```

## 15. CPU / GPU Telemetry Contract

Telemetry is read-only, non-authoritative, and isolated from media work.

Exact GPU command:

```text
nvidia-smi --query-gpu=temperature.gpu,utilization.gpu,memory.used,memory.total,power.draw,power.limit,fan.speed --format=csv,noheader,nounits
```

Exact CPU data sources:

```text
/proc/stat
sensors -j
AMD k10temp Tctl
```

All subprocesses use structured argument lists, `shell=False` behavior, and a three-second timeout.

Observed live idle values included:

```text
CPU utilization: 0.6–1.7%
CPU Tctl: 61.8–64.75°C
GPU utilization: 0%
GPU temperature: 44°C
VRAM: 5 / 16303 MiB
GPU power: approximately 11.8 / 300 W
GPU fan: 0%
```

The browser polls every three seconds. Missing commands, timeout, non-zero exit, malformed output, or unavailable individual metrics produce `Unavailable`/partial telemetry without failing or cancelling media work.

No thermal control or automatic action exists.
